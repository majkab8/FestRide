# FestRide frontend

React + Vite + TypeScript client for the FestRide API. Setup and run instructions
are in the [main README](../README.md#frontend-react--vite--typescript).

- `src/i18n.tsx`: Polish / English copy, dates and plural forms
- `src/api.ts`: typed client for the FastAPI backend
- `src/pages/`: Landing, Events (list + Leaflet map), Search (sentence search),
  RideDetail, Home, Drive (driver dashboard), OfferRide, Login / Signup
- `src/styles.css`: the "v3 sunset poster" design tokens, light and dark
